# teki.ge

Teki.GE-ის საიტი: საინჟინრო მომსახურება სასტუმროებისთვის, მაღაზიებისთვის, კაფეებისა და რესტორნებისთვის (ელექტროობა, გათბობა-გაგრილება, გენერატორი).

## ფაილები

- `index.html` — ერთგვერდიანი საიტი; CSS და JS შიგნითაა, სხვა აწყობა არ სჭირდება.
- `assets/brand/` — TEKI ლოგოს ნაკრები: SVG (ტექსტი კონტურებადაა გადაყვანილი), PNG @2x, favicon და აპლიკაციის ხატულა. ბრილიანტში „T“.
- `.nojekyll` — GitHub Pages ფაილებს ისე აქვეყნებს, როგორც არის.

## ჰოსტინგი: GitHub Pages

Pages ქვეყნდება `main` ბრანჩის ძირიდან. ყოველი push `main`-ზე საიტს ავტომატურად განაახლებს.

დროებითი მისამართი: https://itconnectge.github.io/teki.ge/

### teki.ge დომენის მიბმა

როცა teki.ge დომენი აქტიური იქნება:

1. DNS-ში:
   - `teki.ge` — A ჩანაწერები: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `www.teki.ge` — CNAME: `itconnectge.github.io`
2. რეპოზიტორის ძირში დაამატეთ ფაილი `CNAME` ერთი ხაზით: `teki.ge` და გააკეთეთ push.
3. Settings → Pages-ში, სერტიფიკატის გაცემის შემდეგ, ჩართეთ **Enforce HTTPS**.

## შეფასების ფორმა

ფორმა მოთხოვნას აგზავნის `index.html`-ში ფორმის `data-endpoint` მისამართზე (JSON POST). ის helpdesk CRM-ში ქმნის კონტაქტს და გარიგებას.

GitHub Pages მხოლოდ სტატიკურ ფაილებს ემსახურება, ამიტომ მიმღები ცალკე უნდა გაეშვას. სანამ `data-endpoint` ცარიელია, ფორმა ვიზიტორს სწერს, რომ დროებით არ მუშაობს, და ტელეფონზე ან ელფოსტაზე უთითებს.
